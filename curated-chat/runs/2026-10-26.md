## 검색 범위

이 프로젝트 검토에서는 IntentLock, KNOWL, C 프로그래밍, "KNOWL", knowl-spark-agent의 5개 검색어로 6개 결과 페이지를 읽었다. 총 106개 검색 항목, 중복 제거 84개 메시지·38개 대화가 검색되었다. 이는 **검색 결과 수**이며 본문 전체 열람 수가 아니다.

실제 본문은 KNOWL UI 설계, IntentLock 배너, IntentLock 네트워크 결제/에이전트 설계, C 과제 업로드의 4개 대화에서 관련 구간을 읽었다. KNOWL 설계 응답은 전체를 읽었지만 다른 긴 대화 전체를 내보내거나 완독하지 않았다. 검색 결과의 대화 수정 시각은 개별 산출물의 변경 증거로 간주하지 않았다.

knowl-spark-agent 검색은 끝까지 반환되었고, 넓은 IntentLock/KNOWL/C 검색은 다음 페이지가 남아 있다. 조회 페이지의 partial_results는 false였지만 모든 과거 후보를 조사한 것은 아니다. README 작업 대화 한 건은 본문 접근 불가였으며 검색 스니펫을 구현 증거로 사용하지 않았다. 이미지·첨부 파일 및 Health 연결 대화, Codex 로컬 대화는 이 검색으로 전부 확인할 수 없다.

## 선택과 보류

- 선택: KNOWL 개인 UI 설계 요청과 실제 설계 응답을 짧은 역사적 설계 노트로 재구성. 명시적 구현 상태와 제안 기능을 분리.
- C: 별도 비공개 c-programming-study-2026의 README와 최근 커밋을 읽어 선행 업로드를 확인. 과제·정수 나눗셈 노트를 중복 복사하지 않았으며 강의·기출 원본은 이번 작업 대상에서 제외.
- IntentLock: Next.js/Toss 구현과 TanStack/Supabase mock 구현의 README를 각각 읽고 서로 다른 프로젝트임을 확인. 배너와 기능명세의 옛 파일 링크는 복구하지 않았고 팀/제3자 이미지·자료 권리와 구현 대응이 불명확한 부분은 보류. 자료를 KNOWL에 섞지 않음.

## 문서 검증 수준

- 소유자 hyscodebase, private, main을 현재 GitHub 메타데이터로 확인.
- 기존 curated-chat 경로가 없는 트리를 확인한 뒤 신규 문서만 준비.
- 현재 README와 query-agent 소스에서 키워드 검색 RPC를 확인. 최적화 라우트 세 개는 기존 트리에 없음.
- 문서 내 출처, 상태 구분, 상대 링크, JSON 형식 및 SHA-256을 확인.
- 앱 코드·루트 README·배포·DB는 변경하지 않음. 앱 빌드나 실행 테스트는 미실행.

파일 해시와 출처 버전은 manifest.json에 기록한다. manifest의 자기 해시는 순환을 피하려고 포함하지 않는다. Git blob SHA와 최종 커밋 readback으로 manifest 자체를 검증한다.
